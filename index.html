One-time setup: add a YouTube key

You opened this file directly. YouTube will not play inside it. Put it on a website, or run python3 -m http.server 8000 in this folder and open http://localhost:8000/culture-music-player.html.

Playing songs inside the page needs a free YouTube Data API key. It lets the page search YouTube and play the first result.

  1. Open the Google Cloud Console, create a project, and enable YouTube Data API v3.
  2. Under Credentials, create an API key. Restrict it to your website address and to YouTube Data API v3, so nobody else can use it.
  3. Paste it below. It stays in this browser only. To set it for everyone, put it in API_KEY near the top of the script.

The free quota allows about 100 searches per day. Each button press or search uses one.
